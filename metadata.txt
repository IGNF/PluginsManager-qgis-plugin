about=PluginsManager is a dedicated manager for IGN plugins in QGIS.
    It allows users to:
    - Install IGN plugins from available repositories (qgis.org or GitHub) based on a given profile
    - Automatically detect available updates for installed IGN plugins and install new versions
    - Organize IGN plugins into IGN menu and customizable toolbars according to user needs

    The goal of this plugin is to simplify the deployment, maintenance and daily use of IGN extensions within QGIS.
